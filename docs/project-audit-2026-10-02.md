## Dependency-ների անվտանգություն

Composer-ի սկզբնական ստուգումը հայտնել էր հրապարակված advisory-ներ Guzzle, Laravel, CommonMark և Flysystem փաթեթների համար։ Տեղադրվել են նույն հիմնական տարբերակների համատեղելի ուղղումները՝ Laravel `12.69.3`, Guzzle `7.15.5`, CommonMark `2.10.3`, Flysystem `3.36.0` և Guzzle-ի երկու ենթակախվածությունները։ Laravel-ի նվազագույն թույլատրված տարբերակը բարձրացվել է։

Npm-ում թարմացվել են Axios-ը՝ `1.20.0`, PostCSS-ը՝ `8.5.28`, Nano ID-ն՝ `3.3.19`, իսկ թեստերի հնացած jsdom-ը՝ `26.1.0`։ Հեռացվել են ծրագրում չօգտագործվող CKEditor, Chart.js, flag-icons և Vuex կախվածությունները։

Հիմնական աղբյուրներ՝ [Laravel advisory](https://github.com/laravel/framework/security/advisories/GHSA-jh5r-qr3c-85q8), [Guzzle advisory](https://github.com/guzzle/guzzle/security/advisories/GHSA-v5mv-p594-2x33), [CommonMark advisory](https://github.com/thephpleague/commonmark/security/advisories/GHSA-97jj-33gv-5xf9), [Flysystem advisory](https://github.com/thephpleague/flysystem/security/advisories/GHSA-cxf4-7mrp-vvpr), [Axios advisory](https://github.com/axios/axios/security/advisories/GHSA-9fr6-4gfg-395g), [PostCSS advisory](https://github.com/postcss/postcss/security/advisories/GHSA-fxqj-rqcc-2cmp)։ Advisory-ի առկայությունը չի նշանակում, որ այս հավելվածում exploit է կատարվել։

Live ընդունման արդյունքները՝

- Արտաքին համակարգչից և սերվերից `https://lager.diagen.am/up`՝ HTTP 200, TLS hostname ստուգումը միացված։
- Առանց token-ի `/api/auth/me`՝ JSON HTTP 401։
- Ժամանակավոր, հինգ րոպեով սահմանափակված token-ով auth, dashboard, branch options, stock matrix և central stock report՝ HTTP 200։ Յուրաքանչյուր ստուգման token-ը անմիջապես ջնջվել է։
- CSV/XLSX/PDF հաշվետվությունները՝ HTTP 200 և համապատասխան ֆայլերի ձևաչափեր։ Կենտրոնական պահեստի յոթ տողի CSV պահուստավորված և ազատ քանակները համընկնում են JSON ցուցադրման քանակների հետ։ Stock matrix CSV-ը նույնպես հասանելի է։
- Build manifest-ի բոլոր 34 asset-ները՝ HTTPS HTTP 200։ Login HTML-ը հղվում է նոր build-ին։
- `/.env`՝ HTTP 403, `/vendor/autoload.php`՝ HTTP 404։
- Ստուգումներից առաջ և հետո stock, movement, audit, receipt, transfer և user աղյուսակների տողերի քանակները նույնն են։

Nginx-ի syntax ստուգումն անցել է։ Ընդհանուր սերվերի կարգավորումներում այլ նախագծերի կրկնվող hostname-ների զգուշացումներ կան․ Lager-ի vhost-ի կրկնություն չի հայտնաբերվել, մյուս նախագծերի կարգավորումները չեն փոփոխվել։ Ժամանակավոր սահմանափակ SSH key-ն նախատեսված է հեռացնելու համար վերջնական Git synchronization-ի ավարտին։

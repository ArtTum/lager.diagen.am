# Նախագծի տեխնիկական աուդիտ — 02.10.2026

Շրջանակ՝ Laravel API, Vue հավելված, մուտքի իրավունքներ և սեսիաներ, պահեստային գործարքներ, հաշվետվություններ, dependency-ներ, թեստեր և տեղակայման հասանելիություն։ Սկզբնական Git revision՝ `230c568`։ Աշխատանքային ծառը սկզբում մաքուր էր։

Ստորև նշված ծրագրային խնդիրները ուղղվել են։ Սերվերի pull-ը օգտատերը կատարում է ինքնուրույն։ Այս աշխատանքի ընթացքում արտադրական ֆայլեր կամ տվյալներ չեն փոփոխվել, և նոր DB migration չի ավելացվել։

## Dependency-ների անվտանգություն

Composer-ի սկզբնական ստուգումը հայտնել էր հրապարակված advisory-ներ Guzzle, Laravel, CommonMark և Flysystem փաթեթների համար։ Տեղադրվել են նույն հիմնական տարբերակների համատեղելի ուղղումները՝ Laravel `12.69.3`, Guzzle `7.15.5`, CommonMark `2.10.3`, Flysystem `3.36.0` և Guzzle-ի երկու ենթակախվածությունները։ Laravel-ի նվազագույն թույլատրված տարբերակը բարձրացվել է։

Npm-ում թարմացվել են Axios-ը՝ `1.20.0`, PostCSS-ը՝ `8.5.28`, Nano ID-ն՝ `3.3.19`, իսկ թեստերի հնացած jsdom-ը՝ `26.1.0`։ Հեռացվել են ծրագրում չօգտագործվող CKEditor, Chart.js, flag-icons և Vuex կախվածությունները։

Հիմնական աղբյուրներ՝ [Laravel advisory](https://github.com/laravel/framework/security/advisories/GHSA-jh5r-qr3c-85q8), [Guzzle advisory](https://github.com/guzzle/guzzle/security/advisories/GHSA-v5mv-p594-2x33), [CommonMark advisory](https://github.com/thephpleague/commonmark/security/advisories/GHSA-97jj-33gv-5xf9), [Flysystem advisory](https://github.com/thephpleague/flysystem/security/advisories/GHSA-cxf4-7mrp-vvpr), [Axios advisory](https://github.com/axios/axios/security/advisories/GHSA-9fr6-4gfg-395g), [PostCSS advisory](https://github.com/postcss/postcss/security/advisories/GHSA-fxqj-rqcc-2cmp)։ Advisory-ի առկայությունը չի նշանակում, որ այս հավելվածում exploit է կատարվել։

## Տվյալների և սերվերի վիճակ

`php tools/audit_legacy_schema.php`-ն տեղային աղբյուրի վրա կատարվել է միայն ընթերցման ռեժիմով։ Ստուգվել են 24 աղյուսակ, 214 սյունակ և 50 նախատեսված արտաքին բանալի։ Բացակայող աղյուսակներ/սյունակներ, տիպերի անհամապատասխանություններ կամ orphan գրառումներ չկան։ Արդյունքը `ready_for_migrations` է․ նախկինում փաստագրված երկու արտաքին բանալիները դեռ սպասում են հին migration-ին։ Աղբյուրի տվյալները չեն փոխվել։

Փաստաթղթերում նշված `104.248.33.127` սերվերը հասանելի է, բայց առկա SSH key-ով `root` մուտքը մերժվել է՝ `Permission denied (publickey,password)`։ `https://lager-diagen.govista.am/up` հարցումը չի անցել TLS hostname ստուգումը՝ `SEC_E_WRONG_PRINCIPAL`։ Certificate-ը և կենդանի հավելվածի ընդունումը պետք է ստուգվեն սերվերում։ Օգտատերը հայտնել է, որ սերվերի pull-ը կատարում է ինքը։

Թեստերն աշխատում են մեկուսացված SQLite բազաներով և Vue/jsdom միջավայրով։ Տեսախցիկի սարքային աշխատանքի, արտադրական տվյալների, backup/restore-ի և release cutover-ի ստուգումների համար գործում է [տեղակայման ուղեցույցը](../DEPLOYMENT.md)։

# Diagen Lager

Պահեստային համակարգ «Դիագեն Պլյուս» կենտրոնական պահեստի և մասնաճյուղերի համար։ Ադմինկենի ամբողջ տեսանելի մասը հայերեն է։ Տեսողական հիմքը վերցված է `swift.rent/erp.swift.rent` կառավարման վահանակի մուգ կողային նավիգացիայից, կապույտ շեշտադրումից և աղյուսակային ձևավորումից։

## Տեղային գործարկում

1. PHP 8.2+ միջավայրում պատճենեք `.env.example`-ը որպես `.env` և լրացրեք տվյալների բազայի մուտքի տվյալները։ Լռելյայն բազան `diagen_lager` է։
2. Համոզվեք, որ տվյալների բազան ստեղծված է, ապա գործարկեք՝

   ```powershell
   php database/init.php
   php database/demo_data.php
   ```

3. Տեղային դիտման համար՝

   ```powershell
   php -S 127.0.0.1:8095 -t public
   ```

4. Կայքի document root-ը պետք է լինի նախագծի `public` պանակը։

Փորձնական ադմինիստրատոր՝ `admin@diagen.am` / `Diagen2026!`։ Նույն փորձնական գաղտնաբառն օգտագործում են նաև `manager@diagen.am`, `storekeeper@diagen.am` և `erebuni@diagen.am` հաշիվները։ Մուտք գործելուց հետո փոխեք գաղտնաբառերը։

## Բաժիններ և գործառույթներ

- Գլխավոր վահանակ՝ մնացորդի քանակ և արժեք, ցածր պաշար, ժամկետներ, մասնաճյուղեր և վերջին շարժեր։
- Մատակարարներ, ապրանքներ, մասնաճյուղեր, օգտատերեր, դերեր և իրավասությունների կառավարում։
- Գնումների մուտք՝ հաշիվ, պայմանագիր, LOT, պիտանելիություն, արժեք և պահեստային տեղ։
- Ընդհանուր մնացորդ՝ ըստ պահեստի և LOT-ի, ներքին օգտագործման FEFO ելք։
- Մասնաճյուղի պահանջագիր՝ մասնակի կամ ամբողջական հաստատում, պարտադիր մերժման պատճառ, FEFO հավաքագրում, ուղարկում և ստացման հաստատում։
- Պահեստի շարժի ժամանակային զտում և CSV ներբեռնում։
- Գույքագրում՝ սկզբնական մնացորդի սառեցում, փաստացի քանակ, տարբերության պատճառ և փակման ճշգրտում։
- Ժամկետների վերահսկում, վերադարձներ, մասնաճյուղային տեղափոխումներ և գործողությունների չջնջվող audit մատյան։

Իրավունքները ստուգվում են յուրաքանչյուր բաժնի և պահպանման գործողության ժամանակ։ Ապրանքի քանակը փոխող հոսքերը գործարքային են և մերժում են բացասական մնացորդը։ Գնումն ու պահեստային շարժը չեն հեռացվում․ սխալի դեպքում կատարեք հակադարձ կամ ուղղիչ գրառում։
